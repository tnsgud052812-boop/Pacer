## 걸음수 집계

`index.html`은 같은 배포 위치의 `data/` 파일을 읽습니다. 로컬 확인은 저장소 루트에서 `python -m http.server`로 웹 서버를 실행합니다. 배포 시 HTML과 수정된 데이터 파일을 함께 반영해야 합니다. 월 목록은 크롤러가 생성하는 `data/months.json`을 사용합니다.

- 매일 API 측정 누적값과 **전날 스냅샷의 측정 누적값**의 차이를 계산합니다.
- 매월 1일에도 전날과 비교합니다. 이전 달 값이 남아 있으면 증가분만 반영합니다.
- 월초(1~2일)에 측정 누적값이 감소하면 월 초기화로 처리하고 초기화 이후 값을 반영합니다. 그 외 날짜의 감소나 전날 자료 누락은 `N/A`로 남깁니다.
- 월별 통계는 그 달의 일별 걸음수를 합산하고, 시즌 통계는 설정 기간의 일별 걸음수를 합산합니다. 같은 날 재실행해도 중복 합산하지 않습니다.
- 일별 CSV의 `월간누적`은 API 측정 원본, `월집계누적`은 일별 차이의 합계입니다. `latest.csv`의 `월누적`과 개인별 파일의 `월누적`은 합계이며, `latest.csv`의 `측정누적`은 원본입니다.
- 측정 간격에 발생한 증가분을 측정 날짜에 귀속합니다. 앱 동기화 지연으로 실제 활동 날짜와 차이가 날 수 있으며, 전날 자료가 없는 날은 정확한 차이를 복원할 수 없습니다.
- 확인된 예외는 `data/statistics_corrections.json`에 기록해 재계산에도 유지합니다. 2026년 10월 1일은 `N/A`로 제외하고, 10월 3일에 확인된 초기화 이후 누적값을 합계에 반영합니다. 해당 값에는 앞선 날짜의 걸음수가 포함될 수 있으므로 3일 하루의 실제 활동량으로 해석하지 않습니다.

기존 저장 통계 재계산(네트워크 요청 없이 `data/` 갱신):

```sh
python rebuild_statistics.py
```

회귀 테스트:

```sh
python -m unittest discover -s tests -v
```
